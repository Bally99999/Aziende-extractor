# Aziende.it Extractor MVP

Web app Streamlit: incolli una pagina di ricerca Aziende.it e prova a estrarre dalle schede aziendali Azienda, Telefono, Dipendenti e Fatturato.

Per usarla senza installare nulla sul PC aziendale, pubblica `app.py` su un hosting Python/Streamlit e apri l'URL dal browser.

Il codice non aggira login, CAPTCHA, paywall o rate limit. Verificare i termini d'uso prima di raccolte su larga scala.
